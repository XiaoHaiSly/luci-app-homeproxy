## 增强

- **URLTest 组**：按测速结果自动选择，可设测速间隔、容差与 failover 模式
- **故障转移组**：按顺序尝试节点，当前节点不可用后自动切到下一个，可设黑名单超时
- **负载均衡组**：支持轮询、最低延迟、一致性哈希、会话保持、固定槽位五种策略
- **DNS 分组**：主 DNS 与国内 DNS 各成一组，均可配置多个服务器，组内可选并行 / 顺序 / 最快 / 稳定四种策略
- **分流规则**：按服务单独指定出口，内置 YouTube、TikTok、Telegram、Twitter/X、Google、Cloudflare、GitHub、AI 服务等预设，也可自定义；每条规则可单独选择主节点、独立 URLTest、故障转移、负载均衡、指定节点、直连或拒绝，并同步为该规则的域名选用对应 DNS；支持拖动排序与单条启停，按顺序匹配
- **XHTTP 支持**：新一代 Xray 传输方式
- **Tailscale**：可作为出口节点，支持自建控制端（Headscale）、exit node、路由宣告与接受、登录状态查看
- **sing-box 面板**：内置 Dashboard
