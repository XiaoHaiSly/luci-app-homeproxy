## 主要增强

- **DNS 分组**：主 DNS 与国内 DNS 各自是一个组，可填多个服务器，按组内策略（顺序 / 并发 / 最快 / 稳定）查询，支持 DNS 劫持
- **DNS 响应校验**：未知域名先问国内 DNS，应答异常（SERVFAIL/NXDOMAIN 等）或指向境外时自动改用远端 DNS，投毒应答不会到达应用；已采用应答直接复用，不重复查询
- **XHTTP 支持**，新一代 Xray 传输方式
- **VLESS 加密**：支持 Xray 的 `mlkem768x25519plus`，连接启用加密的新服务器必须填写
- **ClientHello 技巧**：服务器名大小写混排、ClientHello 填充扩展，配合 uTLS 指纹绕过按字节比对的过滤
- **sing-box 面板**：内置 Dashboard sing-box官方面板
- **Balancer 组**：主节点与分流规则均可选用负载均衡组，支持轮询、最低延迟、一致性哈希、会话保持、固定槽位五种策略。成员的延迟直接复用核心的后台检测结果，不额外发起测速；可配置延迟容差倍数、切换容差与切换容差比例。
- **分流规则**：按服务单独指定出口。内置 YouTube、TikTok、Telegram、Twitter/X、Google、Cloudflare、GitHub、AI 服务（非大陆）等预设，也可自定义规则；每条规则可单独选择走主节点、独立 URLTest、指定节点、直连或拒绝，并同步为该规则的域名选用对应的 DNS。支持拖动排序和单条启停，规则按顺序匹配。
